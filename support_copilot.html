Support Copilot

Type a message as a customer. The agent checks the (simulated) account and knowledge base, decides whether it can resolve it directly or should escalate to a human — and shows its reasoning before answering.

How this works: the agent is given a small simulated customer account and a short policy knowledge base (below) as its only source of truth — it can't see real data, and it's instructed to say so rather than invent an answer if something isn't covered. This is the same pattern a real deployment would use, just with mock data standing in for a real CRM/helpdesk connection.
